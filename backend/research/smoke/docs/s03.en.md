# Sprint 42 retrospective — Payments team

Attendees: payments team, product owner, QA lead.

What went well:
- The refund flow redesign shipped on time and the support tickets about refunds dropped by a third.
- Pairing on the flaky integration tests paid off; the nightly build has been green for nine days.

- Code reviews waited too long on Fridays.

Action items:

- Add a second reviewer rotation for Fridays (owner: team lead).
- Move the demo to Thursday afternoons starting next sprint.
