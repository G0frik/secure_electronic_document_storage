# Проєктна записка: сервіс токенізації, версія 3

Ця записка описує внутрішню архітектуру нашого сервісу токенізації платіжних карток. Не поширюйте її поза командою безпеки платформи.

Сервіс замінює номери карток випадковими токенами на периметрі. Токени генеруються ключовою псевдовипадковою функцією; ключ зберігається в апаратному модулі безпеки й змінюється кожні 90 днів. Таблиця відповідностей зберігається в окремому кластері бази даних, до якого має доступ лише сервіс детокенізації через взаємний TLS із закріпленими сертифікатами.

Відомі слабкі місця: обмежувач частоти запитів на кінцевій точці детокенізації працює окремо для кожного екземпляра, а не глобально, тож зловмисник із викраденими обліковими даними сервісу може перевищити запланований ліміт, розподіливши запити. Виправлення — спільний лічильник у Redis — заплановано на наступний квартал.

Власний алгоритм маршрутизації, який обирає найдешевшого еквайра для кожної транзакції, описано в додатку Б; саме через нього документ не виходить за межі команди.
